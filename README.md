# ControlDeck
Notification Center widget (macOS 14+): Wi-Fi, Bluetooth, Dark Mode, brightness/volume steppers, Now Playing with album art (Music + Spotify).

## Install (easy)
1. Unzip. Open Terminal, type `bash ` (with a space), drag `install.sh` into the window, press Return.
2. Sign in to GitHub in the browser when it opens (free account; first time only).
3. Wait about 5 minutes. Then right-click the clock > Edit Widgets > ControlDeck.

Needs Homebrew (https://brew.sh). No Xcode needed.

## Remove
`pkill ControlDeck; rm -rf /Applications/ControlDeck.app`; remove the widget; delete from System Settings > General > Login Items.
